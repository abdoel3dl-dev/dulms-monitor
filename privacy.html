Privacy Policy

Last updated: 29 October 2026

DULMS Monitor is a personal automation tool operated by a single user for that user's own Delta University LMS account. This policy explains what data it handles.

Data accessed

  • DULMS academic data: the owner's assignments, quizzes, exams, grades, attendance and portal notifications, read using the owner's own credentials.
  • Google Calendar: permission to create and update events on the owner's calendar using the calendar.events scope.
  • WhatsApp: the owner's phone number, used only to deliver notifications to the owner.

How data is used

Data is used solely to generate reports and reminders for the owner. Calendar events are written to the owner's own Google Calendar. Message content is sent only to the owner's WhatsApp number.

Storage

Credentials and OAuth tokens are stored as encrypted GitHub Actions secrets. Synchronization state is stored in a private GitHub repository controlled by the owner.

Sharing

No data is sold, shared, or disclosed to third parties. Data is not used for advertising or profiling.

Retention and deletion

State is retained until the owner deletes it. The owner can revoke access at any time from the Google Account permissions page, and can delete the private state repository.
